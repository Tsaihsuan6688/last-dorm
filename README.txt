末日宿舍 v1.1｜GitHub Pages 上線包
1. 解壓縮此 ZIP。
2. 在 GitHub 建立新的 Public repository，例如 last-dorm。
3. 將 index.html 和 assets 資料夾上傳至 repository 根目錄（不要多包一層資料夾）。
4. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
5. 等 GitHub Pages 顯示網站網址，打開後即可操作。
本機存檔：同裝置同瀏覽器會自動儲存；手機與電腦需使用「存檔」匯出/匯入 JSON，尚無自動雲端同步。
若舊版曾在同一網站使用過，本機舊存檔優先，請自行匯出備份後再決定是否重置。
提醒：網站公開不等於存檔公開；但不建議在任務標題輸入敏感個資。
